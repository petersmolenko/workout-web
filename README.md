# Workout App (Vue 3 + API)

Приложение тренировок: история, конструктор новых, отчёты «план/факт».
Работает в паре с сервером `../server/` (FastAPI + SQLite).

## Запуск

1. Сервер:   `cd server && source .venv/bin/activate && uvicorn main:app`
2. Приложение: открой `app/dist/index.html` двойным кликом
   (или для разработки: `cd app && npm install && npm run dev`)

Если сервер не запущен, приложение честно скажет об этом и перейдёт в
режим просмотра: история из JSON, зашитого в бандл на момент сборки
(создание и отчёты недоступны).

## Экраны

- **История** — тренировки с сервера: поиск, фильтры (группа/год),
  карточки раскрываются кликом; детали грузятся лениво (GET /workouts/{id}).
  У своих тренировок есть кнопка «Отчёт»; факт показывается зелёными чипами
  под планом, пропуски и комментарии — рядом.
- **+ Новая** — конструктор: дата, группы мышц, упражнения из справочника
  (селект по группам), схема «подходы × повторения × вес», «последний в отказ»,
  примечание. plan.raw собирается автоматически в стиле тренера.
  Сохранение — POST /workouts, статус planned.
- **Отчёт** (внутри карточки) — строки по каждому плановому подходу
  с предзаполненными весом/повторениями: снял галочку = не сделал,
  поправил цифры = сделал иначе. Комментарий по упражнению, «пропустил»
  целиком, общий итог. POST /workouts/{id}/fact; повторная отправка
  перезаписывает факт (отчёт можно править).

## Структура

    src/api.ts                       — HTTP-клиент к серверу (+ проверка /health)
    src/App.vue                      — режим api/local, вкладки, фильтры, кэш деталей
    src/components/WorkoutCard.vue   — карточка: детали, кнопка и режим отчёта
    src/components/ExerciseItem.vue  — упражнение: план + факт чипами
    src/components/NewWorkoutForm.vue— конструктор тренировки
    src/components/ReportForm.vue    — форма отчёта по факту
    src/components/DictPanel.vue     — справочник упражнений
    src/utils.ts, src/types.ts       — форматирование, типы данных

## Обновление зашитых данных (для offline-режима)

    cp ../db/workouts.json ../db/exercises.json src/data/ && npm run build

Адрес API по умолчанию http://127.0.0.1:8000; переопределить при сборке:
`VITE_API_BASE=http://192.168.1.10:8000 npm run build`
